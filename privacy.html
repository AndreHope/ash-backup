The application uses Google Drive to store and restore selected business backup files. Google user data is used only for this purpose.

Google user data is not sold, used for advertising, or shared for unrelated purposes.

Backup files are stored in the authorized Google Drive account.

The account owner can delete backup files and revoke application access at any time.
